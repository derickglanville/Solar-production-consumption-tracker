Dashboard Overview

What this dashboard is tracking

This dashboard combines Sunrun production, NYSEG import and export readings, irradiance, weather, and contract assumptions in one place.

Production and Grid Flow

Tracks daily production, import, export, and rolling averages so you can see how the system is behaving day to day.

Virtual Consumption Estimate

Because there are no consumption CTs installed, the app estimates self-consumption and home usage from production, grid readings, seasonality, and weather.

Contract Tracking

Compares observed average production against the Sunrun production guarantee and shows whether your current pace is ahead or behind.

Financial View

Estimates electricity value, grid cost, lease cost, and monthly or annual savings using the current settings saved in the app.

The dashboard currently estimates monthly savings from your observed solar production, estimated grid imports, and the lease assumptions in your settings. A negative number means current costs are exceeding the electricity value produced.

Billing Interpretation

Production guarantee context

The contract guarantee averages about {{ "%.1f"|format(billing_outlook.guarantee_daily_kwh) }} kWh/day. Your current observed pace is {{ "%.1f"|format(billing_outlook.projected_daily_kwh) }} kWh/day, which supports the lower-usage NYSEG outlook if this production trend holds.

What should improve first

During sunny months, the NYSEG energy-charge portion should usually be the first thing to shrink. The fixed service charges and the Sunrun lease remain, so the utility bill may not drop to zero even when production is strong.

Best planning number

For budgeting, it is reasonable to plan around about ${{ "{:,.0f}".format(billing_outlook.combined_contract_expected_monthly_charge) }}/month combined on average, while recognizing that solar-heavy months can be lower and winter or cloudy stretches can run higher.
